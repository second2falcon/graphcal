# Security policy

## Supported versions

Only the latest release of GraphCal gets security fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub instead: go to the repository's **Security** tab and click **Report a vulnerability**.

Include what you found, how to reproduce it, and which GraphCal and Nextcloud versions are affected. You'll get an acknowledgement within a week, and we'll keep you posted until it's fixed. Once a fix is released, the advisory is published, crediting you unless you'd rather not be named.

## Scope

In scope: this app's code, such as the OAuth sign-in flow, the token storage, the change-notification webhook and the sync between Nextcloud and Microsoft Graph.

Out of scope: vulnerabilities in Nextcloud itself (report them to [Nextcloud's bug bounty](https://hackerone.com/nextcloud)) or in Microsoft 365 / Entra ID (report them to the [Microsoft Security Response Center](https://msrc.microsoft.com/)).
